# Birthday Surprise Website

Is project me 25 August ke liye Countdown aur Surprise Reveal website hai.

## Files included:
1. `index.html` - Complete website code
2. `song.mp3` - Aapka bheja hua gaana
3. `README.md` - Documentation

## GitHub Upload Guide:
1. Is ZIP file ko download karke extract (unzip) karein.
2. GitHub par naye repository me teeno files (`index.html`, `song.mp3`, `README.md`) upload karein.
3. Settings > Pages me jaakar branch ko `main` set karein aur save karein.
